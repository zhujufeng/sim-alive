# Giffgaff 保号助手

一个完全静态的 Giffgaff 保号小工具。点击按钮后，浏览器会拉取同目录下约 120KB 的 `payload.txt`，用于产生一次移动数据使用记录。

## 使用

1. 上传 `index.html` 和 `payload.txt` 到 GitHub 仓库。
2. 把 `index.html` 里的源码链接改成你的仓库地址。
3. 在 GitHub 仓库的 `Settings -> Pages` 启用 GitHub Pages。

## 注意

- 使用前关闭 Wi-Fi。
- 尽量关闭其他应用的移动数据权限。
- 完成后立即关闭移动数据。
